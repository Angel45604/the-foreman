Run design · cost · blast radius · cleanup
What ran

Frozen-packet effort sweep, per the Codex investigation’s P0 recommendation. ONE frozen copy of the-cartographer bundle (1,861 lines), reviewed by codex-gate under a fresh root thread per cell — no resume across variants, fast mode held OFF throughout so it cannot confound. Core arms: terra@ultra (current default, control), terra@max, terra@xhigh. Optional extension: sol@max, sol@ultra (same-packet model-family comparison) and gpt-5.5@xhigh (the known-good pre-Jul-9 anchor). Per arm we record auto-spawned subagent count and task names, active wall time, token totals, and blocker count by severity and class.

Cost

One bundle round per arm at the tier the gate already runs daily: 3 arms is roughly 25-45 min, 6 arms roughly 60-100 min (the xhigh/max arms should be materially faster than ultra if the fan-out hypothesis holds). Codex credits only; no Anthropic spend. A phase-review P2 gate is running right now at terra@ultra, so arms are queued behind it rather than run concurrently.

Blast radius

Read-only. codex-gate invokes Codex with --sandbox read-only, approval_policy=never and a config-isolated CODEX_HOME, so it cannot write to the repo. Only new directories under ~/.claude/codex-gate/runs/<experiment-session>/ are written. No repo mutation, no branch, no commit, no push, no PR, nothing sent externally, no GitHub issue touched. Model and effort are passed per invocation via env for the experiment only — the committed defaults in codex-gate.sh are NOT edited, so this decides nothing on its own.

Cleanup

All arms land under one experiment session slug; deleting that one directory removes everything. The running P2 gate is left strictly alone — no shared round paths, no signals sent to it. Verdict JSONs are retained as the evidence base for the remedy decision that follows.
